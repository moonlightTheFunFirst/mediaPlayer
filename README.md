# Qt製メディアプレイヤー 開発仕様書（ドラフト）

## Windows版の実装状況（2026-09-11）

WMV・MP4・AVIの基本再生を実装しました。以下の仕様全体のうち、現在は基本再生段階です。

- ビルドして起動：`windows\rebuild_and_run.bat`
- クリーンビルドして配布フォルダを生成：`windows\rebuild_and_deploy.bat`
- 配布版の起動：`windows\output\mediaPlayer.exe`（フォルダ全体が必要）
- 開発環境：Qt 6.8.3 MSVC x64、Visual Studio Build Tools 2022、CMake。
- 実装済み：ファイル選択、単一ファイルのドラッグ＆ドロップ、コマンドラインから開く、再生／一時停止、停止、シーク、時間表示、音量・ミュート、アスペクト比維持、全画面切り替え、再生エラー表示。
- 未実装：プレイリスト、履歴・途中再開、設定保存、全画面時の操作バー自動非表示、仕様にある全ショートカット。

詳細なビルド・配布手順と検証結果は [windows/README.md](windows/README.md)、依存ライブラリは [windows/THIRD_PARTY.md](windows/THIRD_PARTY.md) を参照してください。

### 再生検証

Windows 11 x64 / Qt 6.8.3 / Qt Multimedia FFmpeg 7.1バックエンドで確認。
配布したDLL・プラグインを使い、Qtの開発用binをPATHから外して統合テストを実行しました。

| コンテナ | 映像 | 音声 | 結果 | 制限・素材 |
| --- | --- | --- | --- | --- |

日本語・空白を含むパス、一時停止中のシーク、停止後の先頭再生、ミュート解除時の音量維持、破損・欠落ファイル、連続したファイル切り替えも検証しました。
音声はデコード済みバッファの取得を確認しており、人による聴取・AV同期評価は未実施です。Qt未導入の別PCでの検証も未実施です。

## 1. 開発目的

動画・音声ファイルを再生できる、シンプルなデスクトップ用メディアプレイヤーを開発する。

動画プレイヤーとしての基本機能に加え、音声ファイルを連続再生できる簡易音楽プレイヤーとしても使用できること。

まずWindows版を完成させる。
将来的にmacOS・Linuxにも対応できる構成とし、OS依存の実装は可能な限り分離する。

## 2. 開発方針

- C++およびQt 6を使用する。
- UIはQt Widgetsを基本とする。
- ビルドシステムはCMakeを使用する。
- 最初に既存のQt環境・コンパイラ・関連ライブラリを確認する。
- 既存プロジェクトがある場合、その構成とコーディング規約を尊重する。
- UI表示は日本語を基本とする。
- ファイル名・パスは日本語を含むUnicodeに対応する。
- 再生処理やファイル解析によりUIを長時間停止させない。
- 初期段階から過度に複雑な設計にせず、動作する最小構成から段階的に実装する。

### 2.1 再生バックエンド

再生バックエンドの第一候補はQt Multimediaとする。

ただし、後述の対象コンテナ・コーデックがすべて再生可能であるとは仮定しない。
実際に使用するQtのバージョン、バックエンド、配布構成で対応範囲を確認すること。

要求を満たせない場合は、FFmpegを直接利用する構成などを検討し、採用理由と実装への影響を説明する。

- UIと再生バックエンドの実装を分離する。
- UIから再生ライブラリ固有のAPIを直接呼び出す箇所を集中させる。
- OSへのコーデックパックの追加導入を前提にしない。
- 開発環境だけでなく、配布先での動作も考慮する。
- 外部ライブラリのライセンスおよび配布条件をREADMEに記載する。

## 5. 必須機能

### 5.1 ファイルを開く

- ファイル選択ダイアログから動画・音声ファイルを開く。
- ウィンドウへのドラッグ＆ドロップに対応する。
- 複数ファイルを選択してプレイリストへ追加できる。
- 「ファイルを開く」は現在のプレイリストを置き換え、最初の項目を再生する。
- 「プレイリストに追加」は現在の再生を中断せず末尾に追加する。
- ドラッグ＆ドロップはプレイリストへの追加として扱う。
- 再生対象が未選択の場合、ドロップした最初の項目を再生する。

### 5.2 再生・一時停止・停止

- 再生
- 一時停止
- 再生／一時停止の切り替え
- 停止

停止時の動作：

- 再生を停止し、表示上の再生位置を先頭に戻す。
- ファイルの選択状態は維持する。
- 次に再生した場合は先頭から再生する。
- 手動停止では次のプレイリスト項目へ進まない。
- 履歴の途中再開位置は、停止操作直前の位置を保存する。

### 5.3 シーク

- 現在位置と総再生時間を表示する。
- スライダーで任意位置へ移動できる。
- スライダーの任意位置をクリックして移動できる。
- ドラッグ中は移動先の時刻を表示する。
- ドラッグ確定時にシークを実行する。
- 再生中にシークした場合は再生を継続する。
- 一時停止中にシークした場合は一時停止を維持する。
- 前後5秒・30秒の相対シークに対応する。
- シーク先は有効な時間範囲内に収める。
- シーク不能または長さ不明のメディアでは、該当操作を無効化する。
- フレーム単位の厳密なシークは初期要件に含めない。

時間表示は、1時間未満なら mm:ss、1時間以上なら hh:mm:ss とする。

### 5.4 音量

- 音量スライダー：0～100%
- ミュートの切り替え
- ミュート解除時は元の音量へ戻す。
- 音量とミュート状態を次回起動時に復元する。

### 5.5 動画表示

- 映像のアスペクト比を維持する。
- ウィンドウサイズに合わせて拡大・縮小する。
- 余白部分は黒で表示する。
- ウィンドウ表示と全画面表示を切り替えられる。
- 全画面表示中も再生操作できる。
- 全画面表示中、操作がない場合は操作バーとカーソルを隠す。
- マウス操作で操作バーとカーソルを再表示する。

### 5.6 再生履歴

- 最近再生したファイルを一覧表示する。
- 履歴をダブルクリックすると、そのファイルを開いて再生する。
- 最大100件を保持し、同一ファイルは重複登録せず最新位置へ移動する。
- 履歴の個別削除と全件削除に対応する。
- 再生開始に成功したファイルを履歴へ登録する。
- 存在しないファイルは、その旨を表示して履歴から削除可能とする。

保存する情報：

- ファイルの絶対パス
- 表示名
- 最終再生日時
- 最後の再生位置
- 総再生時間（取得可能な場合）

再開位置は定期的に保存し、ファイル切り替え・停止・アプリ終了時にも更新する。

動画は履歴から途中再開できること。
音声は初期設定では先頭から再生すること。

- 動画と音声それぞれに、途中再開の有効／無効設定を用意する。
- 再生完了したファイルの再開位置は先頭へ戻す。
- 履歴には「先頭から再生」操作も用意する。
- 起動時に履歴を復元しても、自動再生はしない。

## 6. 簡易音楽プレイヤー機能

### 6.1 音声再生時の表示

音声のみのファイルでは、黒い動画表示だけにならないようにする。

取得可能な情報を表示する。

- 曲名
- アーティスト
- アルバム名
- 再生時間
- 埋め込みジャケット画像

メタデータがない場合は、ファイル名を曲名として表示する。
ジャケット画像がない場合は、共通のプレースホルダーを表示する。

音声情報の取得に失敗しても、再生可能であれば再生を続行する。

### 6.2 プレイリスト

- 動画と音声を混在して登録できる。
- 曲名またはファイル名と再生時間を表示する。
- 現在の再生項目を強調表示する。
- ダブルクリックで指定項目を再生する。
- 項目の追加・削除・全件クリアができる。
- ドラッグ操作などで再生順を変更できる。
- 前の項目・次の項目へ移動できる。
- 再生終了後は次の項目を自動再生する。
- 最終項目の終了後は、リピート設定に従う。
- 現在再生中の項目を削除した場合は停止し、勝手に別項目を再生しない。
- プレイリストと選択位置を次回起動時に復元する。
- 復元時は自動再生しない。

初期段階では、外部プレイリスト形式の読み書きは不要とする。

### 6.3 再生モード

- 通常再生
- 1曲リピート
- 全曲リピート
- シャッフル

シャッフルはリピート設定と独立して切り替えられること。

- シャッフル時は、可能な限り全項目を一巡するまで同じ項目を繰り返さない。
- シャッフル時の「前へ」は、実際の再生履歴を戻る。
- 1曲リピート中でも、手動の「次へ」で別項目へ移動できる。

### 6.4 連続再生時のエラー

- 再生できない項目はエラー状態として表示する。
- 自動連続再生中は、再生できない項目を飛ばして次へ進む。
- 全項目が再生不能な場合は停止する。
- リピート設定によってエラー項目を無限に巡回しない。

## 8. キーボード操作

| キー | 操作 |
|---|---|
| Ctrl+O | ファイルを開く |
| Space | 再生／一時停止 |
| 左右キー | 前後10秒シーク |
| Shift+左右キー | 前後30秒シーク |
| 上下キー | 音量調整 |
| M | ミュート切り替え |

テキスト入力中は、文字入力を優先する。

## 9. 設定とデータ保存

次の情報を保存・復元する。

- ウィンドウ位置とサイズ
- サイドパネルの表示状態
- 音量
- ミュート状態
- 最後にファイルを開いたフォルダ
- 動画・音声それぞれの途中再開設定
- リピート設定
- シャッフル設定
- プレイリスト
- 再生履歴

設定はQSettingsなどを使用する。
履歴・プレイリストはJSONなど、管理しやすい形式で保存する。

- 保存失敗時に既存データを破損させない。
- 設定ファイルが破損していても、可能な範囲で初期値へ復旧して起動する。
- 再生元ファイルは変更しない。
- 画面構成の変更などでウィンドウが画面外に出た場合、表示可能な位置へ補正する。

## 10. 内部構成

以下の責務を分離する。
クラス名は参考であり、既存構成に応じて調整してよい。

- MainWindow：画面構成とユーザー操作
- PlaybackController：再生状態と操作の管理
- MediaBackend：再生ライブラリとの接続
- PlaylistModel：プレイリストと再生順の管理
- HistoryStore：履歴の管理・永続化
- SettingsStore：設定の管理・永続化

考慮事項：

- 読み込み中、再生中、一時停止、停止、再生終了、エラーを区別する。
- ファイルを素早く切り替えても、前のファイルの通知でUIが上書きされない。
- 再生位置の更新で、操作中のシークスライダーを戻さない。
- 音声と映像を同期させる。
- 再生終了後やファイル切り替え時に、不要なリソースを解放する。
- 大量のファイルを追加した際、情報取得でUIを固めない。

## 11. エラー処理

以下の場合、アプリを異常終了させず、理解できるメッセージを表示する。

- ファイルが存在しない。
- ファイルへアクセスできない。
- ファイルが破損している。
- コンテナまたはコーデックに対応していない。
- 映像または音声のデコードに失敗した。
- 音声出力機器を利用できない。

技術的な詳細はログへ出力する。
ユーザー向けメッセージには、対象ファイルと問題の概要を表示する。
